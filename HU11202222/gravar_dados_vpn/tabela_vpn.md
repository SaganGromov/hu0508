# Tabela: Registro de Autenticação Corporativa

## Informações Gerais

| Atributo                | Valor                                                                                                      |
|-------------------------|------------------------------------------------------------------------------------------------------------|
| **Nome da Tabela**      | REGISTRO DE AUTENTICAÇÃO CORPORATIVA                                                                                           |
| **Descrição**           | A tabela tem como objetivo registrar os eventos de acesso remoto corporativo realizados por meio da VPN do Banco, oferecendo rastreabilidade completa das conexões estabelecidas pelos colaboradores. Essa estrutura permite o monitoramento detalhado de cada sessão de acesso, incluindo informações sobre o dispositivo utilizado, o método de autenticação aplicado e os endereços de rede associados ao evento. |
| **Volumetria Mensal**   | 10 milhões |

---

## Colunas

| Coluna Lógica                 | Coluna Física | Datatype    | Null     | Descrição                                                                                                                                                                  |
|-------------------------------|---------------|-------------|----------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CÓDIGO IDENTIFICADOR DO MONITORAÇÃO                  | CD_IDFR_MTA   | decimal(11) | NOT NULL | Código sequencial único que identifica cada registro inserido na tabela, garantindo sua individualização para fins de consulta e rastreabilidade das operações registradas. |
| CÓDIGO ÚNICO DA TRANSAÇÃO      | CD_UNCO_TRAN  | char(43)    | NULL     | Código único que identifica a sessão de login na VPN durante todo o ciclo do evento. Este identificador, gerado pela solução de acesso remoto no início da conexão, permanece inalterado durante todo o registro, permitindo o rastreamento completo da sessão estabelecida. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado. |
| TIMESTAMP DA TRANSAÇÃO                     | TS_TRAN       | timestamp   | NOT NULL | Data e hora exatas em que o evento de login na VPN foi registrado.                                                                                                         |
| NÚMERO DA PARTIÇÃO                     | NR_PTC        | smallint   | NOT NULL | Número que representa o mês em que a transação foi realizada, sendo utilizado exclusivamente como critério de particionamento físico da tabela para otimização do acesso aos dados. Este atributo é derivado automaticamente do timestamp do evento e permite a organização eficiente dos registros em partições mensais.                                           |
| CÓDIGO ENDEREÇO LÓGICO DE ORIGEM                  | CD_END_LGC_OGM | char(15)    | NULL     | Endereço IP de origem do dispositivo no momento do login, correspondente ao IP fornecido pela operadora de telecomunicações ou rede de acesso do colaborador. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado.              |
| CÓDIGO ENDEREÇO LÓGICO CORPORATIVO                | CD_END_LGC_CPTV | char(15)    | NULL     | Endereço IP atribuído ao dispositivo do colaborador na rede interna do Banco durante a sessão VPN, correspondente ao IP alocado pela infraestrutura corporativa para comunicação na rede privada. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado. |
| NOME MÉTODO DE AUTENTICAÇÃO               | NM_MTD_AUT    | char(30)    | NULL     | Método de autenticação utilizado pelo colaborador para estabelecer a conexão VPN. Este atributo identifica a forma pela qual a identidade do usuário foi validada durante o processo de login. Exemplos: AutenticaBB — autenticação via aplicativo proprietário do Banco do Brasil; Personal Certificate — autenticação por certificado digital pessoal instalado no dispositivo; Standard — autenticação por usuário e senha; MDM — autenticação via gerenciamento de dispositivo móvel corporativo. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado. |
| NOME DO DISPOSITIVO                     | NM_DSVO       | char(50)    | NULL     | Nome do hostname do dispositivo utilizado pelo colaborador no momento do acesso à VPN, permitindo a identificação do equipamento na infraestrutura de rede corporativa. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado.    |
| CÓDIGO ENDEREÇO FÍSICO               | CD_END_FSCO   | char(22)    | NULL     | Endereço físico de controle de acesso à mídia do dispositivo utilizado pelo colaborador durante a sessão VPN. Este identificador único de hardware da interface de rede permite a individualização e rastreabilidade do equipamento de acesso. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado.                             |
| CÓDIGO IDENTIFICAÇÃO DE DISPOSITIVO  | CD_IDFC_DSVO  | char(40)    | NULL     | Identificador único do dispositivo utilizado para estabelecer a conexão VPN. Este atributo permite o reconhecimento e rastreamento do equipamento ao longo do tempo, independentemente de alterações em outros atributos do dispositivo. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado.                                  |
| CÓDIGO DE IDENTIFICAÇÃO DE ACESSO                  | CD_IDFC_ACSS  | char(60)    | NULL     | Fingerprint — valor de hash que representa o certificado digital utilizado na autenticação do dispositivo na VPN. Este atributo permite a identificação e validação do certificado empregado na conexão, garantindo a integridade e autenticidade do acesso. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado.                |
| NOME SISTEMA OPERACIONAL           | NM_SO         | char(20)    | NULL     | Nome do sistema operacional instalado no dispositivo do colaborador no momento do acesso à VPN. Exemplo: Windows. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado.                                                          |
| CÓDIGO VERSÃO DO SISTEMA OPERACIONAL | CD_VRS_SO     | char(10)    | NULL     | Versão do sistema operacional instalado no dispositivo do colaborador no momento do acesso à VPN. Exemplo: 10. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado.                                                             |
| CÓDIGO TIPO DE CONEXÃO                     | CD_TIP_CNXO   | char(10)    | NULL     | Protocolo de tunelamento utilizado para estabelecer a conexão VPN entre o dispositivo do colaborador e a infraestrutura corporativa. Exemplos: IPSec — protocolo de segurança em camada de rede; SSL — protocolo de segurança baseado em camada de transporte. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado.            |
| CÓDIGO DO USUÁRIO              | CD_USU        | char(9)     | NULL     | Chave de identificação do colaborador no diretório corporativo, utilizada para associar o evento de acesso à VPN ao funcionário responsável pela conexão. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado.                  |
| TEXTO GRUPO DE ACESSO   | TX_GR_ACSS    | char(254)   | NULL     | Grupo de acesso ao qual o colaborador pertence, determinando os recursos e permissões disponíveis durante a sessão VPN. Este atributo permite a segmentação e controle de acessos conforme as políticas de segurança corporativa. Pode ser nulo quando o sistema de origem não enviar a informação, seja por erro no envio ou por o evento não ter atingido a etapa que gera esse dado.                                         |
