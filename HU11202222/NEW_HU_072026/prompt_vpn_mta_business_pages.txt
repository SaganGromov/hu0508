4. MÓDULO COMPARTILHADO — org_enrichment.py
--------------------------------------------------------------------------------

Arquivo novo:
  `acr_controle_acesso_dashboard/streamlit_app/org_enrichment.py`

Conteúdo mínimo:

  ```python
  import re
  from typing import Optional
  import streamlit as st
  from curio_service import integracao_curio
  from curio_models import PAYLOAD_OP292018V3

  _MATRICULA_RE = re.compile(r"^[A-Za-z]\d{7}$")


  def is_matricula(chave: str) -> bool:
      return bool(chave) and bool(_MATRICULA_RE.match(chave.strip()))


  @st.cache_data(ttl=600, show_spinner=False)
  def fetch_org_data(matricula: str) -> Optional[dict]:
      if not is_matricula(matricula):
          return None
      payload = {**PAYLOAD_OP292018V3,
                 "codigoClientePesquisa": matricula.upper()}
      return integracao_curio("op292018v3", payload)


  ORG_COLUMNS_PT = {
      "codigoPrefixoDependenciaAtual": "Prefixo Dependência",
      "codigoUnidadeOrganizacionalDependenciaUsuario": "Unidade Organizacional",
      "codigoInstituicaoOrganizacionalUsuario": "Instituição Organizacional",
      "codigoTipoUsuario": "Tipo Usuário",
      "codigoComissaoUsuario": "Comissão",
      "codigoReferenciaOrganizacionalPerfil": "Referência Perfil",
      "numeroMatriculaUsuario": "Matrícula",
  }


  def flatten_org(record: Optional[dict]) -> dict:
      if not record:
          return {v: None for v in ORG_COLUMNS_PT.values()}
      return {v: record.get(k) for k, v in ORG_COLUMNS_PT.items()}
  ```

Ambas as páginas devem importar `fetch_org_data`, `is_matricula`,
`flatten_org`, `ORG_COLUMNS_PT` daqui.
